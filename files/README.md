# Мини-апп «Шале»: заказ еды в Telegram

## Что внутри

- `index.html` — мини-апп (меню, корзина, доставка или самовывоз, время, телефон, комментарий)
- `menu.json` — меню (45 позиций, цены в сумах). Редактируется без изменения кода
- `bot.py` — бот: приветствие, приём заказа, пересчёт суммы по меню, отправка в группу персонала
- `requirements.txt` — зависимости

## 1. Создать бота

1. В Telegram откройте @BotFather, отправьте `/newbot` и получите токен.
2. Отправьте `/setdescription` и `/setname` по желанию.

## 2. Группа персонала

1. Создайте группу, добавьте в неё бота и дайте право отправлять сообщения.
2. Напишите в группе любое сообщение.
3. Откройте в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id": -100...}`. Это `STAFF_CHAT_ID`.

## 3. Хостинг мини-аппа

Telegram открывает мини-апп только по HTTPS. Загрузите `index.html` и `menu.json` в одну папку на любом статическом хостинге: GitHub Pages, Netlify Drop, Cloudflare Pages, Vercel. Адрес страницы будет `WEBAPP_URL`.

## 4. Запуск бота

Бот работает постоянно, поэтому нужен сервер или хостинг для процессов: Render, Railway, VPS.

```bash
pip install -r requirements.txt
export BOT_TOKEN="123456:ABC..."
export STAFF_CHAT_ID="-1001234567890"
export WEBAPP_URL="https://your-site.example/index.html"
python bot.py
```

## Как работает заказ

1. Клиент пишет боту `/start` и нажимает «Открыть меню».
2. В мини-аппе он выбирает блюда, доставку или самовывоз, время и вводит телефон.
3. Мини-апп передаёт заказ боту, а бот пересчитывает сумму по `menu.json`, поэтому подменить цены нельзя.
4. Заказ приходит в группу персонала. Для доставки указан адрес и напоминание вызвать курьера вручную.
5. Администратор звонит клиенту, называет номер карты и подтверждает заказ.

## Ограничения первой версии

- Заказ отправляется только при открытии мини-аппа через кнопку «Открыть меню» (с клавиатуры). Если его открыть по ссылке из другого места, данные боту не придут.
- Выбор времени «Ко времени» работает только на сегодня. Предзаказ на другой день добавим отдельно.
- Оплата переводом: статус «оплачено» отмечает персонал вручную.
- Номер карты в приложении не хранится. Его выдаёт хостес, как вы и сказали.
- Курьер Яндекс вызывается вручную. Интеграция с API Яндекс Доставки потребует договора.
- Заказы не сохраняются в базе, история хранится только в чате персонала.
